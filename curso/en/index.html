Before the first session

  1. Run generar_datos.ps1 to produce the five practice data sets. They are already generated in curso/datos, and their English version in curso/datos/en; you only need to run it again if you want a variant with a different seed.
  2. The five CSV files are also already copied into PCAPro/datos/en/, so they can be loaded from the interface itself without leaving the application.
  3. Work through the five practicals yourself in PCAPro and check them against the keys.
  4. Print the participant's manual or export it to PDF (File → Print → Save as PDF).
  5. Take the screenshots marked in the manual at the resolution of the classroom projector.
About the data The five data sets are simulated. They do not represent real measurements and must not be used to report scientific results. Their ranges are calibrated to be physically plausible, and their latent structure is known: that is why the participant can check whether they reached the right result, something that is never possible with real data.

How to cite PCAPro

If you publish using this platform, cite it

Barrera-Guzmán, L. Á. (2026). PCAPro: an offline, browser-based platform for guided principal component analysis (version 1.1.0) [software]. Zenodo. https://doi.org/10.5281/zenodo.22649709

In the text: ‘The analysis was carried out in PCAPro (Barrera-Guzmán, 2026)’.

The How to cite PCAPro section of the participant's manual explains this in more detail, and section 6.4 of the platform itself has buttons for copying the reference in APA or BibTeX.
