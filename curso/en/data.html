Practice data sets

Workshop on Principal Component Analysis with PCAPro

Simulated data All five sets were generated by computer for this workshop. They are not real measurements and must not be used to report scientific results. Their ranges are, however, calibrated to be physically plausible, and their internal structure is known: that is how you can check whether you reached the right result.

What each one contains

1 · Soils

Ninety sampling sites spread across three positions on a hillslope (upper slope, mid slope and floodplain). Three chemical properties were measured —organic matter, total nitrogen and available phosphorus— and three physical ones —sand, clay and bulk density—. This is the set “that comes out well”: use it as a reference for what a trouble-free analysis looks like.

2 · Seeds

One hundred and twenty seeds from one wild and one cultivated species, with nine morphometric and compositional variables. This set has three hidden problems. Finding them is the exercise.

3 · Disparate scales

One hundred experimental units with seven variables whose magnitudes range from pH (around 6.5) to a volume in cubic millimetres (hundreds of thousands). It is analysed twice: unscaled and with z standardisation.

4 · No structure

Eighty plots with six environmental variables that bear no relation to one another. It serves to recognise when a PCA is not appropriate, and to see how a widely used criterion can mislead you.

5 · Integrated project

A complete agronomic experiment: 150 plots, four treatments (control, irrigation, fertilisation and both), three blocks, twelve response variables measured on the plant and the leaf, and the final yield. It also has a few missing cells that you will have to decide how to handle.

Yield is not an active variable In the integrated project, Yield_kg_ha is the outcome variable. You must set it as a supplementary quantitative variable: that way it is projected onto the axes without having helped build them, which is what lets you then state which dimensions it is related to.

File format

  • Comma-separated CSV, UTF-8 encoding with BOM (Spanish-language Excel opens them correctly).
  • Decimal separator: point. In PCAPro, leave automatic detection on.
  • First row: variable names. First column: observation identifier.
  • Missing data appear as an empty cell or as NA.
